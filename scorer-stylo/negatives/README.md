# Negatives (optional, for the stylometric classifier)

AI-written answers to the same prompts as your corpus documents. Name each
file after the corpus `family_id` it answers, inside a folder named for the
source, for example `negatives/opus_plain/outliers_essay.txt` and
`negatives/opus_style/outliers_essay.txt` (told to imitate you).

These files are generated from your assignments and are ignored by git.
Never add drafts of the task you are judging.
